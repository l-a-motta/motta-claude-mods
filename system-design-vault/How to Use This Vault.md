> This vault is a folder of linked notes, read with the free app [Obsidian](https://obsidian.md). No plugins or accounts needed.

## Opening it

1. Install [Obsidian](https://obsidian.md/download) (Windows, Mac, Linux, iOS, Android).
2. Choose **Open folder as vault** and pick the `system-design-vault` folder.
3. If Obsidian asks whether to trust the vault, either answer works: this vault uses no plugins.

Notes open in **reading view**, so you can't change them by accident. To make your own notes in the margin, press **Ctrl/Cmd + E** to switch to editing.

## Moving around

| Do this | To |
| --- | --- |
| Click a link | Open that note |
| **Ctrl/Cmd + click** a link | Open it in a new tab (good for deep dives) |
| Hover a link | Peek at the note without leaving this one |
| **Ctrl + Alt + ←** / **→** (Mac: **Cmd + Option + ←** / **→**), or your mouse's back button | Go back / forward |
| Click the trail at the top (🏠 › Part 1 › …) | Jump up a level |
| The **Keep going** box at the end | Next or previous lesson |

The left sidebar has three tabs: **Bookmarks** (the curated starting points), **Files** (every note, in folders) and **Search**.

## Finding things

- **Ctrl/Cmd + O** opens the quick switcher: type a few letters of any topic or abbreviation (*k8s* won't work, but *LB*, *AuthN*, *RAG*, *CDN*, *ETL* will).
- **Ctrl/Cmd + Shift + F** searches inside every note. Useful filters:
  - `tag:#level/basics caching` — only the plain-English notes
  - `tag:#level/deep-dive` — only the technical notes
  - `path:"Part 2"` — only AI system design
  - `"cache invalidation"` — an exact phrase
- The [[Glossary]] lists every term with a one-line definition.
- **Graph view** (Ctrl/Cmd + G) shows how topics connect, colored by part. Deep dives are hidden there to keep it readable.

## Learning with it

- Pick a path from [[00 Start Here#🧭 Pick a path|Start Here]] and **tick each box** when you finish a lesson. Obsidian saves your ticks.
- Try the **Check yourself** questions before revealing the answers. Recalling beats rereading.
- Read the basics first, even if you're technical. The analogies make the deep dives stick.
